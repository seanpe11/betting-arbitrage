# Betting Arbitrage

Simple bot that takes advantage of Polymarket and ProphetX orderbook betting to find arbitrage opportunities. This mainly works since both platforms allow orders for books instead of fixed odds from a centralized bookmaker.

Don't be surprised if the bot is not profitable; the real motivation for this project is to learn how to create a dockerized bot that I'll be adding to my kubernetes cluster, that requires HA, writes to a database, and makes periodic programmatic checks and places bets.
